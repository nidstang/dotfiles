# Formato de GLOSSARY.md
`GLOSSARY.md` es el lenguaje canónico de este espacio de trabajo de enseñanza. Todos los explainers, ejercicios y registros de aprendizaje deben adherirse a su terminología. Construirlo es en sí mismo parte del aprendizaje: comprimir un concepto en una definición ajustada es evidencia de que el usuario lo entiende.
## Estructura
```md
# Glosario de {Tema}
{Una o dos frases describiendo el tema que cubre este glosario.}
## Términos
**Hipertrofia**:
Crecimiento muscular impulsado por tensión mecánica y estrés metabólico a lo largo de sesiones de entrenamiento repetidas.
_Evitar_: Volumen, ponerse grande
**Sobrecarga progresiva**:
Incrementar sistemáticamente la demanda sobre un músculo a lo largo del tiempo — vía carga, volumen o intensidad.
_Evitar_: Apretar más, subir de nivel
**RPE (Rate of Perceived Exertion)**:
Una autovaloración de 1–10 de lo duro que se sintió una serie, donde 10 es fallo y 8 significa que quedan dos repeticiones en el tanque.
_Evitar_: Puntuación de esfuerzo, valoración de intensidad
```
## Reglas
- **Añade un término solo cuando el usuario lo entienda.** El glosario es un registro de conocimiento comprimido, no un diccionario que el usuario lee para aprender. Si al usuario acaban de presentarle un concepto, espera hasta que pueda usarlo correctamente antes de promocionarlo aquí.
- **Sé opinionado.** Cuando existen varias palabras para el mismo concepto, escoge la mejor y lista las demás como alias a evitar. Así se comprime el lenguaje.
- **Mantén las definiciones ajustadas.** Una o dos frases. Define qué ES el término, no qué hace o cómo hacerlo.
- **Usa los términos del propio glosario dentro de las definiciones.** Una vez un término está en el glosario, prefiérelo en todas partes — incluido dentro de otras definiciones. Esto es lo que hace que los términos complejos sean más fáciles de captar más tarde.
- **Agrupa bajo subencabezados** cuando emerjan clústeres naturales (p. ej. `## Anatomía`, `## Programación`). Una lista plana está bien cuando los términos cohesionan.
- **Señala las ambigüedades explícitamente.** Si un término se usa de forma laxa en el campo más amplio, anota la resolución: "En este espacio de trabajo, 'serie' siempre significa una serie efectiva — los calentamientos se siguen por separado."
- **Revisa según se profundice el entendimiento.** Una definición que el usuario escribió en la semana uno puede estar equivocada en la semana seis. Actualiza en el sitio; no dejes entradas obsoletas.
